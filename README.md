## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```

### 4. Code Quality & Linting
```bash
npm run lint
```

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (App Router, Server & Client Components)
- **Language:** TypeScript 5 (Strict Mode)
- **Styling:** Tailwind CSS 3 with custom Dark Editorial Palette & CSS Variables
- **Icons:** Lucide Icons (`lucide-react`)
- **Animations:** Framer Motion & CSS Micro-Interactions
- **Testing & Screenshot Engine:** Playwright Chromium (Automated UI verification)
- **Internationalization:** Bilingual (Russian & English) with instant toggle and `localStorage` persistence
- **SEO & Metadata:** Dynamic Open Graph images, Sitemap generator, Robots.txt, and custom DFZ icon
